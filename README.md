# AI 工具衝擊下的教學因應策略

- 線上看：GitHub Pages（`docs/`）
- 操作：← → 翻頁、`O` 總覽、`S` 補充資料、`N` 講稿、`F` 全螢幕
- 頁碼與 Canva 原稿一一對應

## 重建

```bash
cd src && python build.py   # 讀 content.py、slides.json（講稿）、supplements.json（補充資料），輸出 ../docs/index.html
```
